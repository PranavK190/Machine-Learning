# KNN Classifier — Iris Dataset
## VTU 22CDL66 Machine Learning Lab — Program 9

**Program Statement:**
Write a program to implement k-Nearest Neighbour algorithm to classify the iris data set.
Print both correct and wrong predictions.

---

## Files

| File | Description |
|------|-------------|
| `knn_iris.py` | KNN using scikit-learn — prints predictions & generates plots |
| `requirements.txt` | Python dependencies |

---

## How to Run

```bash
pip install -r requirements.txt
python knn_iris.py
```

---

## Output
- Correct & wrong predictions printed for all test samples
- Accuracy, Confusion Matrix, Classification Report
- `knn_results.png` — Confusion matrix heatmap + Accuracy vs K graph
